# LeetCode Practice Log

用于记录手写题、LeetCode 解题代码、复盘笔记与学习进度。

## 仓库结构

```text
.
├── solutions/          # 按题目保存解法代码
├── notes/              # 专题笔记、错题复盘与方法总结
├── templates/          # 解题记录模板
└── progress.md         # 总体学习进度
```

## 使用方式

1. 在 `solutions/` 下按题号新建题目目录，例如 `0001-two-sum/`。
2. 保存可运行的代码，并在同目录 README 中写下思路、复杂度和易错点。
3. 每完成或复盘一道题，就更新 `progress.md`。
4. 通用技巧与专题总结放入 `notes/`。

## 推荐命名

```text
solutions/0001-two-sum/
├── README.md
└── solution.py
```

目标不是只记录 AC，而是留下能够再次理解和手写出来的解题过程。
